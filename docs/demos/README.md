# Product demo

[Watch/download the 39-second demo](cliplane-demo.mp4) · [Poster](demo-poster.png) · [Evidence](evidence.json)

The light studio runs a real edit → rights review → approval → render → download flow.
The original motion source is uploaded and analyzed before the visible recording starts.
The closing eight seconds play the actual downloaded 720 × 1280 export.

The video uses normal interaction speed, restrained focal zooms and concise annotations.
Processing waits are cut and disclosed. No slide sequence, title cards or music were added.
Both the edited MP4 and exported clip were fully decoded and probed; metadata and hashes
are in evidence.json. The fixture uses original procedural geometry and generated engine
sound, with no external assets or game footage.

[Portable capture/edit/verification bundle](cliplane-demo-source.tar.gz) contains nine
allowlisted text files: scripts, edit plan, timings, sanitized workflow evidence and a
README. The source generator is included; capture can use the checked-in original fixture.
Raw takes and downloaded exports remain outside Git under /workspace/work/demo-v2.
No hosted raw recording or release upload is implied.
