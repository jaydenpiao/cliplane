# Product demo

[Watch/download the 45-second workbench demo](cliplane-demo.mp4) · [Poster](demo-poster.png) · [Evidence](evidence.json)

The demo shows a real live-composition → filmstrip/trim → layout/caption → save →
rights review → exact-revision approval → render → download flow. It opens with an
excerpt of the actual result and ends with the full downloaded eight-second
720 × 1280 export. The original fixture is really uploaded and analyzed before
visible recording begins, in a fresh isolated synthetic workspace.

The 44.733-second video is 1600 × 900 at 30 fps. Interactions run at normal speed,
with restrained focal zooms and concise annotations. Processing waits are cut and
disclosed. There are no title cards or added music. The edited demo is silent; the
downloaded export retains its original generated audio.

Source, export and final MP4 were probed and fully decoded; all use fast-start
metadata. The saved final file also played in Chromium with advancing time. Actual
workbench/rendered/download screenshots, a final contact sheet and eleven decoded
final-file frames were inspected. Evidence records dimensions, durations, hashes,
matching edit/rights approval revisions and sanitized HTTP results.

The fixture is original procedural geometry and generated sound, with no external
assets or game footage. Capture uses the “Your studio” interface, light mode and
the America/Los_Angeles browser timezone. No account credentials or cookies appear
in the video or evidence. This is a local workflow demonstration, not a deployment.

[Portable capture/edit/verification bundle](cliplane-demo-source.tar.gz) contains
exactly nine allowlisted text files for this take: scripts, plan, actual timings,
resolved cuts, sanitized workflow evidence and a README. Capture uses
packages/test-fixtures/nightdrift-original.mp4; its optional original generator is
included. Raw takes and downloaded exports stay outside Git under
/workspace/work/workbench-v5/demo/take-02. No hosted raw recording or release upload
is implied.
