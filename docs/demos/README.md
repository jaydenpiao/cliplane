# Product demo

[Watch/download the 40-second demo](cliplane-demo.mp4) · [Poster](demo-poster.png) · [Evidence](evidence.json)

The studio runs a real edit → rights review → approval → render → download flow.
The checked-in original motion fixture is uploaded and analyzed before the visible
recording starts. The closing eight seconds play the actual downloaded 720 × 1280 export.

The 39.767-second video is 1600 × 900 at 30 fps. It uses normal interaction speed,
restrained focal zooms and concise annotations. Processing waits are cut and disclosed.
No slide sequence, title cards or music were added. The source, exported clip and edited
MP4 were probed and fully decoded; all three MP4s have fast-start metadata. Evidence
records current dimensions, durations, hashes and sanitized HTTP results.

The fixture uses original procedural geometry and generated engine sound, with no
external assets or game footage. The take uses the “Your studio” interface and the
America/Los_Angeles browser timezone in a local synthetic demo workspace.

[Portable capture/edit/verification bundle](cliplane-demo-source.tar.gz) contains exactly
nine allowlisted text files: scripts, edit plan, actual timings, resolved cuts, sanitized
workflow evidence and a README. Capture uses packages/test-fixtures/nightdrift-original.mp4;
the optional original source generator is included. Raw takes and downloaded exports
remain outside Git under /workspace/work/design-v3/demo-final. No hosted raw recording or
release upload is implied.
