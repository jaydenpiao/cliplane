# Security policy

This is a local MVP and has not undergone a public-hosting security audit. See the
documented public-beta gate in docs/security/threat-model.md before accepting public uploads.

Please report vulnerabilities privately through the repository's private vulnerability
reporting feature when enabled. If unavailable, contact the repository owner through a
private channel before sharing sensitive details. Do not put tokens, private footage,
credentials or exploit payloads containing personal data in public issues.

Include affected version, reproduction using synthetic data, expected behavior and
impact. Only the latest development version is supported at this stage.
